# Ender-Stinger

CAD files for the Ender-Stinger build by zwirbel3d.

## Y-axis motor mount

The Y-axis motor mount is a modified design. Its very likely original is
[Ender 3 Pro Y-axis motor mount by FT256 / Mayoroffk](https://cults3d.com/en/3d-model/tool/ender-3-pro-y-axis-motor-mount)
(original file: `Motor_mount_Mayoroffk.stl`). The remix author is approximately 99% confident in this identification.

a [STEP export](CAD/Y-Axis%20Low.step) is also provided.
